# eggs

Pacote legado de configuracao para servidor Minecraft/Spigot, com arquivos de servidor, ajustes Bukkit/Spigot e resource pack.

## Conteudo

- `server.properties`: configuracoes principais do servidor Minecraft.
- `bukkit.yml`: configuracoes Bukkit.
- `spigot.yml`: configuracoes Spigot.
- `resource pack.zip`: pacote de recursos.
- `eula.txt`: aceite da EULA do servidor.

## Uso

Copie os arquivos para uma instalacao de servidor compatível com Bukkit/Spigot e revise as configuracoes antes de iniciar o servidor.

## Status

Legado/arquivo de configuracao. A auditoria de 2026-06-16 classificou este repositorio como candidato a arquivamento, principalmente por ser um pacote antigo, pequeno e sem codigo de aplicacao.

## Cuidados

- Verifique a versao do servidor antes de reutilizar os arquivos.
- Nao publique mundos, logs, plugins privados ou dados de jogadores.
- O repositorio estava publico no GitHub; recomenda-se tornar privado ou arquivar se nao houver uso atual.
